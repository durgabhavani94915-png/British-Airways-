# British Airways Customer Reviews Analysis using GenAI

## Project Overview
This project analyzes British Airways customer reviews to understand customer satisfaction, identify critical feedback, and generate AI-assisted customer apology drafts.

## Objectives
- Analyze customer ratings and reviews.
- Identify critical reviews with ratings of 1–3.
- Explore common negative keywords in customer feedback.
- Visualize service ratings using Python.
- Generate customer apology drafts using Generative AI.

## Tools and Technologies
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- NLTK
- LangChain
- Groq API
- Jupyter Notebook

## Key Findings
- Total reviews: 3,819
- Valid overall ratings: 3,696
- Critical reviews: 1,695
- Critical reviews represent approximately 45.86% of valid ratings.

## Business Value
This analysis can help identify service improvement opportunities, understand customer complaints, and support more consistent customer communication.

## Note
AI-generated apology drafts should be reviewed by a human before being sent to customers.
